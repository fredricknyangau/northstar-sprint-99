## Day 3 Reflection

### What happened
Continued working on my assigned backend tasks, mainly the order-status endpoint and the rule-based support-query auto-tagging. I tested the endpoints using Postman and worked through a few request configuration issues before getting the expected responses.

I also reviewed how my backend implementation fits into the wider system, particularly the transition toward using the team's PostgreSQL database as the database work became available.

### What went well
- Successfully implemented and tested my assigned API functionality using Postman.
- The rule-based classification was straightforward to implement, test, and explain.
- Progress on the database side gave me a clearer understanding of how my endpoints will eventually interact with real data.
- I became more comfortable troubleshooting API requests instead of relying only on automated tests.

### What was harder than expected
- Configuring Postman correctly took some trial and error, particularly around the JSON request body.
- Keeping my changes aligned with the team's Git workflow required more discipline as other team members continued working on the project.
- Connecting the API to the database requires careful integration rather than simply changing the data source.

### Self-assessment
Day 3 was a useful step forward in my backend development. I was able to move beyond writing the endpoint logic and actually verify the behaviour through Postman. I also have a better understanding of the integration work still required between the API and database. Going forward, my focus is on completing that integration cleanly while keeping my implementation consistent with the team's architecture and requirements.
